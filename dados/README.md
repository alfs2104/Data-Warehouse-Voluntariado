# Dados

A base utilizada no projeto teve como origem uma planilha de voluntariado hospitalar referente aos meses de janeiro e fevereiro de 2025.

A base original possuía 52 registros reais.

Para fins educacionais e analíticos, foram utilizados dados fictícios adicionais, mantendo a estrutura da base original.

Após a expansão, a base passou a conter 4.224 registros.

Os dados expandidos foram utilizados exclusivamente no contexto acadêmico do projeto.

## Arquivo

A pasta contém a planilha utilizada como base para a construção do Data Warehouse.

A planilha apresenta os dados utilizados na construção das tabelas dimensionais e da tabela fato.
